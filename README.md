# Booking Gedung

A fullstack building/venue booking application built with Laravel backend and Flutter mobile app.

## Features

### Backend (Laravel)
- RESTful API for buildings, rooms, bookings
- User authentication with Sanctum
- Admin dashboard for managing bookings
- Email notifications

### Mobile (Flutter)
- Browse buildings and rooms
- Book rooms with date/time picker
- View booking history
- Push notifications

## Tech Stack

**Backend:** Laravel, MySQL, Sanctum
**Mobile:** Flutter, Dart, HTTP
